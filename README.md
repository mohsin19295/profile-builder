# <p align="center">Profile-Builder</p>

A resume builder built with plain `HTML`, `CSS`, and `JavaScript`. No build step or dependencies: open `index.html` in a browser.

## Features

- **Live preview** that updates as you type, in two templates (Classic and Modern with a sidebar), with a custom accent color and font.
- **Sections:** personal details with photo, professional summary, work experience, education, projects, skill groups, certifications, languages, achievements, and interests.
- **Repeatable entries** that can be added, removed, and reordered. Experience and education support "currently here", which shows "Present".
- **Download PDF:** opens the print dialog with print-only styles; choose "Save as PDF". The PDF has real, selectable text, which applicant tracking systems (ATS) can read.
- **Download Word:** downloads a `.doc` file (with the photo embedded) that opens in Microsoft Word.
- **Auto-save** in the browser's local storage, plus **Import / Export JSON** for backups or moving between devices.
- Responsive layout for desktop and mobile.
